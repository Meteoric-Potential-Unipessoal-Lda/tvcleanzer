# Translations

Russian is the source language: every user-visible string in `lib/` is written in Russian
and wrapped in `tr('…', [args])` (`lib/l10n/l10n.dart`). `{0}`, `{1}` are placeholders.

- `keys.json` — all Russian strings (index = row), including package-database labels/reasons.
- `langs.json` — the translated languages (Russian is not listed: it is the source).
- `tr_<lang>.json` — translations in the same order as `keys.json`; an empty string means
  "not translated yet" (falls back to English, then Russian).
- `lib/l10n/strings.dart` — generated by `python3 tools/l10n/gen.py`; do not edit by hand.
  The generator refuses rows whose `{n}` placeholders differ from the Russian source.

Adding a string: write it in Russian inside `tr(...)`, append it to `keys.json` and a
translation at the same index to every `tr_<lang>.json`, then run `gen.py`.

Adding a language: add its code to `langs.json` and `supportedLanguages` in
`lib/l10n/l10n.dart`, create `tr_<code>.json` (same length as `keys.json`), add it to
`CFBundleLocalizations` in `ios/Runner/Info.plist`, run `gen.py`.

30 languages (Nov 2026): ru, en, uk, es, pt, de, fr, it, be, kk, uz, hy, az, ka, ky, tr, pl,
ro, zh (Simplified), ja, ko, hi, id, vi, th, nl, cs, el, hu, sv. The 22 added in 1.3.35 were
machine-translated; be/kk/uz/hy/az/ka/ky would benefit from a native speaker's review.

## TV launcher (launcher/)

The launcher is plain Java, so it has its own small table class `T` (`T.t("русский текст")`,
`T.f("Показать все ({0})", n)`), generated by:

    python3 tools/l10n/gen_launcher.py

Keys are collected from the `T.t`/`T.f` literals in `launcher/src`. Each string is taken from
`tools/l10n/launcher/<lang>.json` (launcher-only strings, `{"русский": "перевод"}`) or, if it is
there, from the app tables above. The TV language comes from the system locale; Russian, tg, tk
and mo show Russian, unknown languages show English. Rebuild the APK with `./launcher/build.sh`.
