# Дополнительные тулзы для ТВ

Сторонние утилиты, которые помогают на отдельных телевизорах. Не часть TVCleanzer.

| Файл | Что это | Где нужно |
|---|---|---|
| `Old_DroidTvSettings.apk` | Старые «Настройки» Android TV (`com.android.tv.settings`). Через них можно выбрать лаунчер по умолчанию там, где родные настройки этого не дают. | ТВ на Android 11+ (minSdk 30), например с Яндекс ТВ |

Скачать: https://github.com/Meteoric-Potential-Unipessoal-Lda/tvcleanzer/raw/main/extras/tv-tools/Old_DroidTvSettings.apk
